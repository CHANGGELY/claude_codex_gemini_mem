# Contributing to Claude Codex Gemini Mem

First off, thank you for considering contributing to Claude Codex Gemini Mem! It's people like you that make this project a great tool for everyone.

## How Can I Contribute?

### Reporting Bugs
* Use the [GitHub Issue Tracker](https://github.com/CHANGGELY/claude_codex_gemini_mem/issues).
* Describe the bug in detail and provide steps to reproduce.

### Suggesting Enhancements
* Open an issue with the tag `enhancement`.
* Explain why the feature would be useful.

### Pull Requests
1. Fork the repo.
2. Create a new branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'Add amazing feature'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

## Coding Standards
* We use **TypeScript** for all logic.
* Ensure all code is commented and follows the existing style.
* Use **Bun** for running scripts and tests where possible.
