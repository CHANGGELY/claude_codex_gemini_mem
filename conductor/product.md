# 产品指南 (Product Guide)

## 初始概念 (Initial Concept)
Gemini-Mem (原 Claude-Mem) 是一个专为 Claude Code 和 Gemini CLI 打造的通用持久化记忆压缩系统。它通过自动捕获工具使用观察结果、生成语义摘要并将其提供给未来的会话，无缝地跨平台（Claude/Gemini）保留上下文。

## 目标受众
1. **Claude Code 与 Gemini CLI 高级用户**：在复杂项目上工作，需要 AI 在会话之间“记住”上下文以避免重复同步背景信息的开发者。
2. **AI 代理开发者**：构建复杂代理工作流，需要持久化记忆和上下文管理参考实现的工程师。
3. **大型项目维护者**：管理大型代码库（如单体仓库、遗留系统）的用户，对于这些项目，上下文的“渐进式披露”对于管理 Token 限制至关重要。

## 核心价值主张
- **连续性**：通过持久化知识，消除大语言模型（LLM）会话的“健忘症”问题。
- **效率**：通过智能搜索仅注入相关的上下文，减少 Token 使用量和延迟。
- **透明度**：提供 Web 界面（Viewer）来可视化代理“记住”并使用的具体内容。

## 关键功能
- **🧠 持久化记忆**：基于 SQLite 的会话、观察结果和摘要存储。
- **🔍 智能搜索**：结合 FTS5（关键词）和 Chroma（向量）的混合检索，精准查找相关上下文。
- **📊 渐进式披露**：一种分层信息检索策略，在上下文质量与 Token 成本之间取得平衡。
- **🖥️ Web 查看器界面**：基于 React 的仪表板 (localhost:37777)，用于实时记忆可视化和管理。
- **🔌 生命周期钩子 (Hooks)**：在会话开始、结束和工具使用期间运行的自动化脚本，无需人工干预即可捕获数据。
- **🌐 多语言支持**：广泛的 i18n 支持，确保全球可用性。
